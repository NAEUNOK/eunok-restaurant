# 간장버터 소고기 덮밥 (규동 스타일)

> **조리시간 15분 · 2인분 · 난이도 하**

---

## 재료

### 메인
- 소고기 불고기감 또는 대패삼겹살 — 300g
- 양파 — 1개
- 대파 — 1/2대
- 버터 — 1큰술
- 밥 — 2공기
- 계란 — 2개 (노른자만 또는 반숙 후라이)

### 양념 (미리 섞어두기)
| 재료 | 분량 |
|---|---|
| 간장 | 4큰술 |
| 설탕 | 1.5큰술 |
| 맛술(또는 소주) | 2큰술 |
| 다진마늘 | 1큰술 |
| 물 | 4큰술 |
| 후추 | 약간 |

**대체 재료**
- 맛술 없을 때 → 물 + 설탕 조금
- 소고기 없을 때 → 돼지고기, 닭다리살 모두 가능

---

## 조리 순서

### 0~3분 · 준비
- [ ] 밥이 없으면 즉석밥부터 전자레인지에 넣기
- [ ] 양파 채썰기 (0.5cm 두께)
- [ ] 대파 어슷썰기
- [ ] 양념 재료 전부 그릇에 붓고 섞어두기

### 3~6분 · 양파 볶기
- [ ] 팬 중불 + 기름 1큰술
- [ ] 양파 넣고 3분간 볶기
- [ ] 양파가 투명해지고 살짝 갈색 돌면 완료

### 6~10분 · 고기 익히기
- [ ] 고기 넣고 겉면 색 변할 때까지 볶기 (2분)
- [ ] 섞어둔 양념 전부 붓고 센불로 올려 끓이기
- [ ] 국물이 자작해질 때까지 3분 졸이기
  > 다 졸이지 말 것. 밥에 비벼 먹을 국물입니다.

### 10~13분 · 마무리
- [ ] **불 끄기**
- [ ] 버터 1큰술 + 대파 넣고 잔열로 30초 섞기
  > 버터는 반드시 불 끄고 넣어야 향이 삽니다.

### 13~15분 · 담기
- [ ] 그릇에 밥 담기
- [ ] 고기와 국물 얹기
- [ ] 가운데 계란 노른자 또는 반숙 후라이 올리기
- [ ] (선택) 통깨, 쪽파 뿌리기

---

## 실패 방지 포인트

1. **양념은 반드시 미리 섞어두세요.**
   팬 앞에서 간장을 붓다 보면 거의 확실하게 짜집니다.

2. **국물을 완전히 졸이지 마세요.**
   밥에 스며드는 국물이 이 요리의 핵심입니다.

3. **너무 짜졌다면**
   물 2큰술 + 설탕 1작은술 추가 후 30초 더 끓이기.

4. **고기가 뭉치지 않게**
   팬에 넣자마자 젓가락으로 펼쳐주세요.
