# 마크다운 간단 정리

마크다운은 일반 텍스트로 문서의 구조를 표현하는 가벼운 문법입니다.
메모, README, 블로그 글까지 폭넓게 쓰입니다.

## 왜 쓰나요?

- **읽기 쉬움** — 변환하지 않은 원문 그대로도 이해됩니다.
- **어디서나 동작** — 깃허브, 노션, 각종 에디터가 기본 지원합니다.
- **버전 관리에 유리** — 그냥 텍스트라 diff가 깔끔합니다.

## 기본 문법

| 요소 | 문법 | 결과 |
| --- | --- | --- |
| 제목 | `# 제목` | 크기별 제목 (`#` ~ `######`) |
| 강조 | `**굵게**`, `*기울임*` | **굵게**, *기울임* |
| 목록 | `- 항목` 또는 `1. 항목` | 순서 없는/있는 목록 |
| 링크 | `[이름](주소)` | 클릭 가능한 링크 |
| 코드 | `` `코드` `` | 인라인 코드 |

### 인용문

> 문서는 짧을수록 읽힌다.
> 길어지면 목차를 넣자.

## 작성 팁

1. 제목은 한 문서에 `#` 하나만 쓰고, 그 아래를 `##`로 나눕니다.
2. 문단 사이는 빈 줄 하나로 구분합니다.
3. 표가 길어지면 목록으로 바꾸는 편이 읽기 편합니다.
